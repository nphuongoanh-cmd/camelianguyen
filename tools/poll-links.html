Poll links for Kit

Type the poll id from the Polls tab of your Google Sheet, or a feedback form id (carnet or mental-leger), then copy the links into your Kit email: one link per answer. Kit replaces {{ subscriber.email_address }} with each subscriber's email when it sends.

One link per answer

In Kit, add a button (or select some text and add a link) for each answer, and paste its link.
